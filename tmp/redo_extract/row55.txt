1. Introduction
Agentic large language model (LLM) systems increasingly
operate as long-horizon programs: they decompose goals
into sub-tasks, interleave tool calls with verification, and
accumulate experience over repeated interactions (Yao et al.,
2022; Schick et al., 2023; Shinn et al., 2023; Wu et al.,
2024). External memory is therefore a core systems com-

ponent for preserving state across sessions and enabling
concurrent multi-agent execution (Packer et al., 2024; Park
et al., 2023; Maharana et al., 2024). At deployment scale,
memory access becomes a bottleneck: retrieval cost grows
with corpus size, shared indexes contend under concurrent
reads and writes, and tail latency worsens under load (Dean
& Barroso, 2013; Guu et al., 2020; Lewis et al., 2020; Douze
et al., 2025; Jayaram Subramanya et al., 2019).
Memory access in agentic workloads is heterogeneous
in both content and intent.
Many requests require re-
trieving declarative evidence from long-horizon interaction
logs (Maharana et al., 2024; Park et al., 2023), while others
benefit from reusing previously successful tool-use proce-
dures (Wang et al., 2023). Treating these cases as a single re-
trieval problem increases context pressure and can reduce re-
liability, motivating a tiered design that separates short-lived
working state, persistent evidence, and reusable skills, and
allocates explicit per-request budgets across tiers (Packer
et al., 2024; Wang et al., 2023).
Sharding the evidence store is a common approach to scal-
ing retrieval: shard-local indexes reduce per-query work,
improve parallelism, and strengthen isolation in multi-tenant
settings (Douze et al., 2025; Malkov & Yashunin, 2018; Ja-
yaram Subramanya et al., 2019; Jin et al., 2024). Sharding
introduces a routing problem: given a query with hard struc-
tured constraints (tenant, scope, permissions), the system
must select a small set of shards to probe while maintaining
high evidence coverage. Probing many shards undermines
efficiency; probing too few can miss required evidence and
degrade downstream quality.
Most deployments rely on static partitions with heuristic
routing (Douze et al., 2025). These mechanisms are dif-
ficult to sustain in agentic settings because (i) correctness
under structured constraints should not depend on a heuris-
tic or learned router (Jin et al., 2024; Gollapudi et al., 2023),
(ii) shard access costs are heterogeneous, for example, pro-
files/summaries versus episodic traces, and (iii) workload
drift can lead either to degraded coverage or to conservative
probing that increases latency.
We present ShardMemo, a tiered memory service that en-
forces scope-correct and budgeted access over sharded stor-
age. Tier A maintains bounded per-agent working state un-
der budget M to stabilize short-term context. In Tier B (ev-

Contributions. This paper makes three contributions:
• System. We introduce ShardMemo, a tiered memory
architecture for agentic LLM systems that separates
per-agent working state (Tier A), sharded evidence
memory with provenance and shard-local ANN in-
dexes (Tier B), and a versioned skill library for reusable
procedures (Tier C). A lightweight tier gate selects
Tier B, Tier C, or both under explicit budgets.
• Method. We propose a scope-correct routing mecha-
nism for sharded evidence retrieval by casting shard se-
lection as masked MOE routing under a hard probe cap
Bprobe. The design includes heterogeneous shard fam-
ilies and cost-aware gating, together with Top-Bprobe
or adaptive Top-P probe selection.
• Training and evaluation. We provide a supervised
router-training protocol from evidence→shard labels
(LoCoMo) using a multi-positive set-likelihood objec-
tive, and evaluate both task quality and memory-access
behavior (probes, vectors scanned, and p95/p99 la-
tency). We additionally evaluate Tier C skill reuse on a
tool-use benchmark and report adoption and efficiency
metrics.
Roadmap. Section 2 surveys related work. Section 3 formu-
lates the budgeted problem. Section 4 describes the Shard-
Memo architecture. Section 5 presents the experimental
evaluation.
2. Related Work
External memory for LLMs and agents.
Retrieval-
augmented generation (RAG) conditions generation on re-
trieved evidence, decoupling per-request context length
from the lifetime of stored information (Lewis et al.,
2020; Karpukhin et al., 2020; Guu et al., 2020). Practi-
cal systems typically use ANN-based, multi-stage retrieval
pipelines (Johnson et al., 2019; Guo et al., 2020). Re-
cent agentic systems extend retrieval to persistent state
and long-horizon execution, e.g., paging between bounded
working context and external stores (Packer et al., 2024),
maintaining profiles and episodic records (Park et al.,
2023), or reusing prior trajectories via reflection and self-
improvement loops (Shinn et al., 2023). Benchmarks such
as LoCoMo emphasizes long-horizon conversational mem-
ory evaluation (Maharana et al., 2024), while multi-hop QA
datasets (e.g., HotpotQA) are frequently used to stress evi-
dence retrieval under longer contexts (Yang et al., 2018). In
contrast to work that primarily targets modeling or prompt-
ing, ShardMemo focuses on memory access at scale: bud-
geted retrieval with constraints under sharded storage.
Procedural memory and skill reuse. Tool-using agents in-
terleave reasoning with action execution (e.g., ReAct, Tool-
former) (Yao et al., 2022; Schick et al., 2023). Systems
such as Voyager maintain reusable skill libraries to reduce
replanning on recurring task families (Wang et al., 2023),
and workflow-oriented memory stores and retrieves reusable
action trajectories (Wang et al., 2024). Tool-use benchmarks
such as ToolBench provide a complementary evaluation axis
focused on executability and action efficiency (Qin et al.,
2023). Tier C in ShardMemo operationalizes procedural
reuse via versioned, schema-checked skill artifacts retrieved
under explicit budgets with a bounded fallback to evidence
retrieval when skills are inapplicable.
Budgeted routing for sharded retrieval. Sharding and
multi-index vector search improve scalability and paral-
lelism (e.g., FAISS), but routing is often heuristic, trading
recall against retrieval work (Douze et al., 2025; Malkov
& Yashunin, 2018; Jayaram Subramanya et al., 2019; John-
son et al., 2019; Guo et al., 2020). Relatedly, federated
search and resource selection study how to choose a small
set of collections/shards under budgets using collection sum-
maries (Callan, 2002; Shokouhi et al., 2011). Structured con-
straints have been addressed via filtered or constraint-aware
ANN search (Gollapudi et al., 2023; Jin et al., 2024). Shard-
Memo builds on these lines by enforcing scope-before-
routing (eligibility masking prior to any semantic selection)
and casting shard probing as masked MOE routing (Shazeer
et al., 2017; Lepikhin et al., 2020; Fedus et al., 2022), en-
abling supervised router training from evidence→shard la-
bels when available and cost-aware gating over heteroge-
neous shard families.

3. Problem Formulation
Agentic LLM systems need memory access that improves
task quality while enforcing (i) hard isolation and compati-
bility across tenants/tools/schemas and (ii) strict per-request
cost/latency budgets. We model tiered memory access as a
constrained optimization.
For a request q ∼D, the service may return Tier A working
context A(q), Tier B evidence RB(q) obtained by probing
a shard set P(q), and/or Tier C skills U(q). Each stored
item x carries metadata m(x). Each tier τ ∈{A, B, C}
defines a scope predicate ψτ(m, q) ∈{0, 1} that is true iff
metadata m is permitted and compatible with request q un-
der Tier-τ constraints. For sequential workloads, we index
requests by t and write qt and ψτ
t (m) ≜ψτ(m, qt). We de-
note per-request budgets by (M, Bprobe, K, R), which cap
Tier A context size, the number of probed Tier B shards, the
number of returned Tier B evidence items, and the number
of retrieved Tier C skills, respectively.
We seek a tier gate g, a Tier B shard router πθ, and a Tier C
skill retrieval policy based on a similarity function sim that
maximize expected task quality under these budgets and
scope constraints:
